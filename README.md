# Event Planner 3D

Interactive 3D event-planning prototype built with React, Vite, and Three.js.

## Run

```bash
cd event-planner-3d
npm install
npm run dev
```

The app loads real GLB furniture models from Khronos glTF sample assets and provides a 3D event layout workspace with navigation, model adding, selection, dragging, transform controls, and export actions.
